# clay-hero — 찰흙 인물 배경 + 타자기 제목 히어로

레퍼런스 2편(꽃집 FLOREN·요양 AURA CARE, 2026-09-19)에서 뽑은 레시피. 분해는 `references/reference-analysis.md`.
핵심 한 줄: **제목은 고객의 순간·고민 한 문장이고, 배경의 찰흙 인물들이 그 문장을 이야기로 증명한다.**

## 0. 이 스킬이 만드는 것 (부품 목록)

| 부품 | 내용 |
|---|---|
| 배경 | 찰흙 인물 스틸 3장 교차 페이드(기본) 또는 6~8초 찰흙 영상 1개(변화 이야기일 때) |
| 그림자 | 카피 쪽(왼쪽·아래)만 눌러주는 그라디언트. 인물 쪽은 안 건드림 |
| 유리 네비 알약 | 브랜드 · 메뉴 4개 · 「문의하기」. 폰에선 브랜드+문의만 |
| 카피 블록 | 한글 라벨 칩 → 제목 2줄 타자기 → 부제 페이드 → CTA 페이드 |
| 플로팅 | 우하단 전화·상담 원형 2개 (SVG, 이모지 금지) |

**배경은 찰흙 인물이다.** 생성 도구가 없다고 그라디언트·추상 무늬·스톡 사진으로 대체하지 않는다. 못 구하면 멈추고 유저에게 말한다.

## 1. 문장 → 이야기 (코드 전에, 유저에게 한 줄 공유)

1. 제목: 그 업종 고객의 순간·고민 한 문장, 2줄. 은유 금지. 예 「꽃이 필요한 모든 순간, / 당신 곁에 함께합니다」 「홀로 남겨진 부모님, / 더 이상 외롭지 않도록」
2. 배경 이야기를 제목에서 뽑는다:
   - 제목이 **"여러 순간"** → 스틸 세트. 같은 인물이 옷·소품만 바꿔 3순간 (입학→졸업→결혼). `references/prompts.md` 2절 표.
   - 제목이 **"전→후 변화"** → 영상 1컷. 혼자(흑백)→함께(컬러)처럼 한 흐름. `prompts.md` 3절.
3. 라벨 칩은 한글(「꽃집 플로렌」). 영문 대문자 라벨 금지.

## 2. 에셋 만들기

`references/prompts.md`의 공통 블록 + 인물 고정문 + 장면 줄. **인물 고정문은 한 글자도 바꾸지 않는다.** 장마다 새 채팅.

Gemini 웹(`gemini.google.com/image`, 무료) 실측 절차 — Chrome MCP:
1. `navigate` → 컴포저에 `+`·「이미지」칩 보일 때까지 대기 → 「가로세로 비율」 클릭 → 16:9
2. `javascript_tool`: `document.querySelector('[contenteditable=true]')`에 `execCommand('insertText')`
3. 전송 화살표 **좌표 클릭 1회**. 화면 전환이 10~50초 늦다. 텍스트가 그대로 보여도 **다시 누르지 않는다**(생성 중지가 눌린다). 40초 뒤 스크린샷.
4. 저장: `img`(naturalWidth>600, blob:) src로 `<a download>` 만들어 `click()` → `~/Downloads/이름.png` (1024×572). 툴바의 다운로드·복사 버튼 좌표 클릭은 자주 무효.
5. `scripts/make-assets.sh still a.png b.png c.png` → `clay-01.jpg…` (✦ 워터마크 제거·jpg). 장당 250KB 이하.
6. 3장을 나란히 놓고 본다: **인물 크기·위치가 장마다 비슷한가.** 다르면 그 장만 다시 뽑는다(크롭으로 억지로 맞추면 흐려지고 머리가 잘린다).

영상은 첫 프레임 스틸을 먼저 만들고 참조 이미지로 넣어 Flow(Veo)/Higgsfield에서 생성 → `make-assets.sh video in.mp4`.

## 3. 조립

`assets/hero/markup.html`·`clay-hero.css`·`clay-hero.js` 를 사이트에 넣는다. 모든 클래스·변수는 `ch-` 접두사.

| 바꾸는 것 | 어디 |
|---|---|
| 브랜드·메뉴 4개·문의 링크 | `.ch-nav` |
| 라벨 칩·제목(2줄, `<br>`로 줄 지정)·부제·CTA·전화번호 | `.ch-copy`, `.ch-float` |
| 인물 위치 (데스크톱 / 폰) | `--ch-pos` / `--ch-pos-m` — 폰은 글자가 아래로 가니 인물은 위로 |
| 글자색·그림자색·유리색 | `--ch-ink`(밝은 벽이면 `#1F1A1C`)·`--ch-shade`·`--ch-glass` |
| 배경 (A) 스틸 3장 / (B) 비디오+poster | `.ch-bg` 안에서 하나만 남긴다 |

등장 타이밍(레퍼런스 실측, JS에 박혀 있음): 배경 즉시 → 350ms 후 제목 타이핑(글자 110ms·공백 60ms·줄 끝 260ms) → 끝나고 250ms 부제 → 650ms CTA. **타이핑 대상은 제목(h1)이다. 브랜드명이 아니다.** 스틸은 2.8초 머묾·0.9초 교차, 화면 밖이면 멈춤.

SPA·해시 라우터면 렌더 직후 `window.CH.mount(el)` 재호출. `--ch-dwell`을 바꾸면 verify.mjs가 그 값을 읽어 대기 시간을 맞춘다.

## 4. 검증 (완료 보고 전 필수)

- 인라인했으면 `node --check` (닫는 script 태그 문자열 주의)
- `node scripts/verify.mjs <URL 또는 file://> <출력폴더>` — 1440·430·390·320 타이핑 중/완료 컷, 제목 원문 일치, 부제·CTA 표시·화면 안, 배경 움직임, 가로 넘침, 콘솔 에러, reduced-motion 즉시 완성. (playwright 필요. 로컬 http 포트가 옛 세션 서버에 잡혀 404 나면 `file://`로)
- 스크린샷을 **눈으로**: 카피 뒤에 인물 얼굴이 오지 않는지, 폰에서 인물 머리가 네비에 잘리지 않는지, 장마다 인물 크기가 비슷한지, 글자 대비
- 함정 목록 `references/pitfalls.md`
