## 등장 타이밍 (실측, 0초 = 페이지 표시)

| 시각 | 일어나는 일 |
|---|---|
| 0.0s | 배경 이미 보임. 제목 첫 글자 시작 (캐럿 `|` 깜빡임) |
| ~1.0s | 1줄 완료 ("꽃이 필요한 모든 순간," / "홀로 남겨진 부모님,") → 캐럿 2줄로 |
| ~2.4s | 2줄 완료. 글자당 약 110~120ms(공백 포함 ~8자/초) |
| ~2.6s | 부제 페이드 인 |
| ~3.0s | CTA 페이드 인 (부제와 0.4s 차) |
| 이후 | 캐럿 2~3번 더 깜빡이고 사라짐 |

## 배경 A — FLOREN: 스틸 4장 교차 페이드

- 같은 세 인물(엄마·아들·아빠), 같은 분홍 회벽, 같은 카메라. **바뀌는 건 옷과 꽃다발뿐.**
  입학(교복+카네이션) → 졸업(학사모+흰 장미) → 결혼(신부·신랑+부케) → 장례(검은 한복·상복+국화)
- 중간 프레임에 학사모가 반투명으로 겹쳐 있음 = 진짜 영상이 아니라 **크로스 디졸브**. 장당 약 2초 머묾.
- 즉 영상 생성기가 필요 없다. 이미지 생성기로 "인물 고정문 + 순간만 바꾼" 스틸 3~4장 → CSS 교차 페이드.
- 이야기 = 제목의 증명: "꽃이 필요한 모든 순간" → 인생의 네 순간을 같은 가족으로 보여준다.

## 배경 B — AURA CARE: 생성 영상 1컷 (6.8초)

- 흑백 찰흙 할머니 뒷모습(홀로) → 오른쪽에서 요양사가 걸어 들어옴 → 마주 보며 손을 잡음 → **손 잡은 자리부터 색이 번짐** → 마지막 컷은 꽃밭 위 컬러.
- 카메라 고정, 인물 크기 큼, 배경 회벽. 색 전환·인물 이동은 이미지로 흉내 못 내므로 영상 모델(Flow/Veo, Kling 등) 필요.
- 이야기 = 제목의 증명: "홀로 남겨진 부모님, 더 이상 외롭지 않도록" → 혼자(흑백) → 함께(컬러).
